# DeepFake Detector 🚀

**DeepFake Detector** – a demo project by **Team Fuzion** built for a NCST to showcase our innovative approach to fighting misinformation using AI.

## Overview

Fuzion DeepFake Detector is a web application that lets you upload an image to determine if the face in it is **real** or **AI-generated**. By quickly spotting deepfakes, our tool aims to curb the spread of false information.

## How It Works

1. **Upload an Image**: Easily drag & drop or select your image.
2. **AI Analysis**: Our deep learning model inspects the face for authenticity.
3. **Instant Results**: Receive a quick verdict on whether the image is genuine or manipulated.
